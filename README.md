## 💡 Key Concepts & Techniques

This challenge covered a wide range of data structures and algorithms. Here are some of the key topics I practiced:

*   **Arrays and Hashing:** Using hash maps and sets for efficient lookups and frequency counting.
*   **Graph Traversal:** Applying Depth-First Search (DFS) and Breadth-First Search (BFS) for grid and graph problems.
*   **Dynamic Programming:** Solving optimization problems by breaking them down into smaller subproblems.
*   **Sorting:** Utilizing sorting to simplify problems involving distance and assignments.
*   **Binary Search:** Finding elements efficiently in sorted arrays.
*   **Two Pointers:** Optimizing solutions for array and string problems.
*   **Prefix Sum:** Calculating sums of ranges in an array efficiently.
*   **Simulation:** Directly modeling the process described in a problem statement.
*   **String Manipulation:** Parsing and transforming strings.

## 🧪 Testing the Solutions

The C++ solutions in this repository are written to be pasted directly into the LeetCode online judge. They each contain a `Solution` class with the required method.

To test them locally, you would need to write your own `main()` function to instantiate the `Solution` class, create test cases, and call the respective method.

**Example Local Test Setup:**

// Include the solution file, e.g., for Day 6

int main() {
    Solution sol;
    std::vector<int> commands = {4, -1, 3};

    std::cout << "Max Euclidean distance squared: " << result << std::endl; // Expected: 25

}
